# 100 模型性价比实测与选型

目标：交付可复算的 100 模型比较表，将通过验证的经济方案接入商品精排。

架构：独立 model_selection_100 模块复用原 ESCI 指标、分区和共享账本；新研究单独冻结，不覆盖旧结论。依据 RouterBench AIQ 做任务适配评分，单列质量门槛、失败和成本不确定性。

技术：现有 Python、DuckDB、PyTorch 本地预排、现有 OpenAI 兼容 HTTP、SQLite。无需安装新依赖或新建账户。

1. `prepare.py`、`PROTOCOL.md`：核查公开模型目录和密钥可见 ID，登记 100 候选以及 12/36/96 条分组新样本；验证去重、历史隔离和固定选择不使用标签。
2. `baseline.py`：本地 GPU 预排新样本，输出固定前十输入及原始全候选；验证原冻结保持不变。
3. `client.py`、`run.py`、`metrics.py`：受控 HTTP、费用预留、可恢复单次调用、质量与 AIQ 复算、初筛/入围/验证边界。定向检查预算、解析、评分、身份和中断行为。
4. 先固定方法哈希，再执行校准及分阶段调用；不删除失败，不在验证上选模型；超预算不继续提交。
5. 输出 XLSX/CSV 表与带来源报告；人工检查表格数字/格式及完整性。对入选方案做有针对性的商品精排接入验收，补充真实项目贡献。

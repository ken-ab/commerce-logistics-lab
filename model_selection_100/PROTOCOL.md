# 100 模型商品重排选型：执行协议

2026-09-08。用户先将全项目总额度调整为480元，随后明确把模型选型与评分任务单独封顶100元（包含已发生校准费）。两项上限同时生效。采用24/60/150条探索规模，并加入准确率、费用、时长和可靠性。此前实验文件与结论保持原样。

## 样本与用途

100个执行模型ID，21个家族；最初19家族名单中不可调用或协议不符合的条目在人工夹具校准后替换，变更记录保留。目录记录不是权重身份认证，返回模型名也记录；不使用免费/折扣线路重复凑数。MiniMind不在当前服务目录，不能与MiniMax混称。

| 阶段 | 共同新查询 | 模型 | 调用数 |
|---|---:|---:|---:|
| 人工协议夹具校准 | 1 | 初始100及必要兼容修正 | 已110次；校准全部完成 |
| 初筛 | 24 | 100 | 2,400 |
| 复测 | 60 | 最多6，含Luna参照 | 最多360 |
| 独立验证 | 150 | 一个预先选定候选与Luna | 最多300 |

约3,170次计划调用。已完成本地预排的480条中，各阶段按原哈希顺序与语言交错截取24/60/150条，共234条不同查询；其余预排结果不参与选择。各阶段不重叠，US/ES/JP等额。若胜出者就是Luna，不做重复同配置调用。人工夹具不计入质量。不可用服务保留未测原因，不补造分数。24条只用于粗筛，不足以证明100模型的精确先后顺序；150条不能保证区分1个百分点的差异。约90%命中率的单模型比例，150条的95%正态近似半宽约4.8个百分点；模型差异另用配对区间。

从ESCI已登记development/validation分区按固定哈希选查询组，只用ID、语言、分区和至少10个候选条件；排除过去排序实验已登记的全部查询组。验证不参与选型。预训练污染无法排除。指标对应标注候选池，不等于全商品库召回或真实用户转化。

全部模型输入同一0.6B本地预排的前10商品、同样的匿名编号和打乱展示次序。保留标题、品牌、颜色、描述前1200字符原文本；标注、商品ID、原排名和分数不发送。模型只重排前十，尾部保持原序；NDCG@10的理想分母仍由完整标注候选池计算，E/S/C/I增益1/.1/.01/0。

统一JSON排列提示，允许单个JSON代码围栏，不从夹杂解释的文本里猜答案。每个编号必须恰好出现一次。固定1024输出上限，使用execution_models.json登记的none/low设置；人工夹具显示部分模型强制推理，已在质量调用前改用low。返回名称只接受登记的精确厂商前缀/版本拼写，Kimi-K2-Thinking返回K2.5的跨型号替换已排除。MiniMax M2/M2.1允许移除一个完整的前置think标签块，原始响应保留，混合流的首答案时间记NA。不要求function calling。比较登记的经济配置，不推断每个模型最大能力。提示与旧三模型工具调用协议不同，只在本轮同题比较。

## 指标字典

| 指标 | 定义与分母 |
|---|---|
| Accuracy / Exact Top1 | 有效输出中首位标签为E的数量÷全部已提交查询。两者是同一个指标，只计一次；格式错误和无回答记0。不是所有商品的分类准确率。 |
| NDCG@10 | 查询级宏平均；未产生有效排列的已提交查询记0。另列回退本地排序后的系统NDCG，不能把回退成绩称为模型答对。 |
| Avg Cost (CNY) | 该阶段全部已提交请求的核算及未知费用预留÷请求数；另列已知token估价、未知费用次数、每千请求费用、每个有效回答成本。不是平台账单。 |
| Avg Latency | 发起HTTP前到完整响应结束或报错的客户端耗时平均值，包含失败等待、网络及供应商排队；不含本地调度等待。另列P50、P95。 |
| API Success Rate | 完整API响应数÷已提交请求；HTTP 200但流不完整不算完整响应。接口返回成功不等于答案正确。 |
| Effective Success Rate | 返回合法完整排列的请求数÷已提交请求；用于可靠性评分。格式错误、截断、超时、HTTP错误分列。 |
| Failure Rate | 1−Effective Success Rate；与成功率互补，不重复计权重。未提交项单列。 |
| 输入/输出/推理/缓存token | 实际usage及各字段覆盖率。输出已包含推理token，不重复收费；未提供字段记NA，不能默认0。 |
| TTFT | 流式首个非空内容或推理片段的客户端到达时间；另列首个答案内容时间。不是纯模型计算时间。 |
| Answer Stream Span | 至少两个答案片段时的首尾到达间隔；单片段或非流式记NA，不当作完整响应时长。 |
| Observed Reasoning Span | 至少两个可见推理片段的首尾到达间隔，仅作诊断。纯思考秒数不可测，统一NA；隐藏推理不填0。 |

同一阶段最多4个并发，按查询交错、轮换模型次序，记录时间和接口。延迟是该网络和服务条件下的结果，不是GPU跑分；不把供应商线路差异归因于权重。流式首片段不一定是一枚token。

## 事先固定的评分

质量Q=(NDCG@10+Accuracy)/2。总分=100×(0.70Q+0.15C+0.10L+0.05R)。R为有效回答率；失败已影响质量，5%的R是额外的可用性偏好，并非独立统计证据。

费用效用C参考RouterBench的零费用/零质量点插值与面积思想：c为每千查询CNY费用，B=5；c≤B时C=1−c/(2B)，否则C=B/(2c)。速度效用L=min(1,2/平均响应秒数)，≤2秒取1。B与2秒参考此前本项目Luna使用量级；权重和阈值是项目部署偏好，不是论文公认公式。

同时保留任务适配AIQ=100QC、原始指标与非支配关系。敏感性使用质量/费用/速度/可靠性权重80/10/5/5与60/25/10/5，并报告B=1、10时AIQ。不能事后按想要的冠军改主分数。

只有完整同批样本才给可比较的总分；部分完成给已观察指标、分母和未完成数。校准未通过和零有效正式响应的模型质量NA，无晋级资格。分数不是录用概率或全球最优认证。

## 选型及独立验证

初筛要求至少23/24有效、身份一致、NDCG不低于同批Luna超过.04、Accuracy不低超过2/24；按总分选最多5个其它模型加Luna。若不足名额不以失败者补齐。

复测60条要求至少59有效、身份一致、NDCG不低于Luna超过.02、Accuracy不低超过2/60。合格者按总分选一个，平分按NDCG、费用、模型ID。两个阶段分开，不混合不同分母排名。

冻结赢家后，在150条独立查询与同配置Luna配对。按查询组配对bootstrap 95%区间；NDCG差值下界≥−.02、Accuracy差值下界≥−.03、至少147有效、身份一致，总分优于Luna，才建议替换。均值费用高于Luna时另要求NDCG差值区间下界>0。否则保留已验证方案，报告不确定，不能换候选反复试验证集。若新协议Luna自己胜出，报告它对本地预排的结果，不声称胜过旧协议Luna。

这套比较决定商品精排组件。业务工具执行、订单确认和报告事实性保持独立验收，不能用排序Accuracy代表整个Agent的任务成功率。

## 预算与审计

共享evidence/api_budget.sqlite计入过去全部核算和预留；480元为全项目硬上限，model-selection-100前缀下的全部费用另受100元硬上限约束。所有110次校准费用计入100元，实时剩余额度以共享账本为准。初筛加校准最多82元，为后续复测/验证留18元。新模块执行新授权；不修改旧冻结代码的300元上限，也不清空旧账本。目录USD/百万token按8CNY/USD保守换算，不假设促销或缓存折扣。

每个HTTP请求先原子预留；失败和中断不能假定免费；有可靠usage才释放多余预留。一个正式模型/查询只提交一次，不自动重试。永久权限错误停止该模型，费用不足停止新增请求。有预留或开始标记的请求不重发，保留缺口。校准用固定夹具；发现通用接口错误须记录修正及额外校准费用，再在质量调用前冻结，不根据质量调提示。

先冻结校准代码与配置，完成接口检查后冻结正式方法、输入、费率、评分和名单。初筛最前6条同题后只按token/耗时/可用性更新费用预测，不根据质量重抽样。修订规模按3000输入/300输出token、当前价目及复测费率中位数估计约85—90元总新增选型费用（包含校准），不是保证完成报价。若长思考或未知费用使100元不足，就停止并报告共同已完成范围；不能偷偷超支，也不能把未测项补成成绩。

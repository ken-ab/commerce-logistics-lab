# 独立验证统计实现登记

在150题验证的任何模型请求发生前，冻结配对统计实现、测试与本文。复测选择唯一候选后，验证只比较该候选与同配置Luna，不重新选人。当前12/60/150修订及原协议的评分与晋级门槛保持原样。

每个模型按原登记顺序连接同一150个查询组，逐项核验组ID、模型ID、原回答排列、重新计算的NDCG/Top1/MRR以及账本请求。缺失查询不能静默删除；已提交但无有效完整排列的质量记0。所有150组齐全才计算正式配对区间，不把只成功的案例作为分母。

使用Python标准库random.Random(20260908)，对150个查询组有放回抽样10,000次。每次同时抽取两模型同一查询组的差值，计算均值；排序后采用线性插值的2.5%与97.5%分位数。抽样不按模型、商品对或成功案例进行，也不按语言分层。三个语言在原固定样本中等额。NDCG、Accuracy与MRR共用固定随机序列；MRR仅作描述。区间是单个指标的边际95%区间，不称为联合95%保证。

非Luna候选的替换门槛：完整150题；有效回答至少147；登记身份一致；NDCG差值下界不低于-0.02；Accuracy差值下界不低于-0.03；主总分严格高于Luna。若平均费用及未知预留高于Luna，还须NDCG差值下界严格大于0。任何一项不通过则保留现有Luna，不改候选、不重复验证以争取通过。

若复测胜出者就是Luna，只运行一次Luna配置。报告其相对于本地预排的配对结果，保留当前模型，不把新JSON提示对本地预排的表现当作优于旧Luna工具调用提示的证据。两种协议未直接比较。

本地预排对照的区间及语言/失败描述不改变晋级。报告结果文件保留输入哈希与账本快照；金额是目录token估价或未知用量预留，不能冒充供应商账单。统计代码不调用API，也不修改原始结果或冻结阶段汇总。

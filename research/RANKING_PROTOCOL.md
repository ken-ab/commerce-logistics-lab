# 公开商品排序实验 v1

数据使用 Amazon ESCI Task 1 `small_version`。项目此前冻结的查询分区保持不变；开发与验证各按 query-group SHA 顺序取每种语言前 200 个 query ID（各 600 个查询），最终测试使用全部 14,496 个官方 Task 1 查询、336,373 个标注候选对。选样只依赖分区、语言、ID 和哈希，未使用标签或成绩。

比较同一标注候选池内的词法 BM25（候选池词频统计，k1=1.2/b=0.75）与官方 Qwen3-Reranker-0.6B 固定检查点。词法基线使用 Unicode 词边界，对无空格日文有已知不足，单独报告各语言。模型读取查询和商品标题、品牌、颜色及前 1200 字符的去标签描述，不能读取 ESCI 标签。模型作者、许可、固定提交和文件 SHA 均见下载清单；不把下载模型当作个人训练成果。

开发集比较通用指令与商品匹配指令，使用 bfloat16、SDPA、512 token 上限；原模型 yes/no 判别方式保留。只计算最后位置词表投影以控制显存，先与未优化版本做同一输入数值对照。批量大小选择只依据能否运行及速度，不依据标签成绩。截断数量、失败、耗时均记录。

主指标 NDCG@10，另报全候选 NDCG、Exact MRR、Exact Top-1。增益 E=1、S=0.1、C=0.01、I=0，依据上游 `ranking/train.py`；上游另一个 TREC 转换辅助脚本存在 S/C 映射不一致，不能混用。相同分数按商品 ID 排序，0 增益查询计 0 并保留。报告查询宏平均与配对 bootstrap 区间，不把随机波动写成提升。

开发选定指令后进行独立验证，只有冻结方法才能打开最终测试。全目录共有 1,814,924 条商品，但本实验是标注候选池排序，不是全目录召回率或真实成交转化率。未标注商品不自动当负例。Qwen 基础训练数据覆盖不足以排除 ESCI 接触；项目分区隔离只能保证本项目不使用最终测试做调参。

来源：[ESCI](https://github.com/amazon-science/esci-data)、[模型卡](https://huggingface.co/Qwen/Qwen3-Reranker-0.6B)、[作者技术报告](https://arxiv.org/html/2506.05176v2)。
